Kit de componentes

Interfaz Hextech

Todos los componentes usan solo lol-ui.css y lol-ui.js, sin dependencias. Pulsa </> en cualquier bloque para ver el HTML y copiarlo. Haz clic en un color para copiar su variable.

Paleta oficial del cliente expuesta como variables CSS (--lol-gold-1 … --lol-black).

Keybinds

Haz clic en una caja y pulsa una tecla, combinación (Ctrl/Alt/Shift + tecla) o botón del ratón. Esc cancela, Retroceso borra. Las teclas repetidas se marcan en rojo. Emite lol:keybind con { action, key }.

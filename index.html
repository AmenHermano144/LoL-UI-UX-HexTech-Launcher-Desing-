Component kit

Hextech Interface

All components use only lol-ui.css and lol-ui.js, no dependencies. Press </> on any block to view its HTML and copy it. Click a color to copy its variable.

Colors

Official client palette exposed as CSS variables (--lol-gold-1 … --lol-black).

Typography

Headings in Beaufort (fallback: Cinzel) and body text in Spiegel (fallback: Inter). If you have the original fonts installed, they are used automatically.
